# Field Notes PoC (PWA)

Мінімальний вебзастосунок, щоб перевірити на телефоні:

- роботу в **офлайн** режимі (Service Worker + IndexedDB);
- **фото** з камери (стискаються до ~1600px JPEG);
- **запис голосу** (MediaRecorder, на Android формат webm/opus);
- **текстові нотатки**;
- сповіщення про **втрату / відновлення з'єднання**;
- просту «синхронізацію»: кнопка **Upload** відкриває системне меню «Поділитися», де треба вибрати **Google Drive**.

Тут немає backend, логіну й AI: це лише перевірка того, що вміє браузер.

## Файли

| Файл | Що робить |
|---|---|
| `index.html`, `styles.css` | UI у стилі платформи |
| `app.js` | IndexedDB, камера, мікрофон, статус мережі, Share |
| `sw.js` | кешує застосунок, щоб він відкривався без інтернету |
| `manifest.webmanifest`, `icons/` | дозволяють встановити застосунок на головний екран |

## Публікація на GitHub Pages

Камера, мікрофон, Service Worker і встановлення працюють **тільки через HTTPS**. GitHub Pages дає HTTPS безкоштовно.

1. Репозиторій має бути **Public**. Для Private потрібен GitHub Pro, Team або Enterprise. Перевірити: Settings → General → Danger Zone → Change visibility.
2. Відкрити **Settings → Pages** (https://github.com/oleksbod/pwa/settings/pages).
3. У блоці **Build and deployment**:
   - **Source:** `Deploy from a branch`
   - **Branch:** `main`, папка `/ (root)` → **Save**
4. Зачекати 1–2 хвилини. Прогрес видно у вкладці **Actions** (workflow `pages build and deployment`).
5. Застосунок буде доступний за адресою **https://oleksbod.github.io/pwa/**. Посилання також з'явиться вгорі сторінки Settings → Pages.
6. Кожен `git push` у `main` автоматично публікує нову версію. Перед пушем не забудь підняти `VERSION` у `sw.js`.

Файл `.nojekyll` вимикає обробку Jekyll: файли віддаються як є.
Усі шляхи в застосунку відносні (`./`), тому він працює з підпапки `/pwa/`.

## Як тестувати (Android, Chrome)

1. Відкрити посилання GitHub Pages **з інтернетом**.
2. Натиснути **Install** у хедері, або «⋮ → Додати на головний екран».
3. Відкрити застосунок з іконки. Відкрити ⚙ Diagnostics і переконатися, що Service worker показує `active`.
4. Увімкнути **режим польоту**. Має з'явитися помаранчевий банер і сповіщення «Connection lost».
5. Створити сесію, зробити 2–3 фото, записати голос, додати текст.
6. Закрити застосунок повністю (зі списку недавніх), відкрити знову: усі дані на місці.
7. Вимкнути режим польоту. Має з'явитися сповіщення «Connection restored» з кнопкою **Upload**.
8. Натиснути **Upload → Drive → вибрати папку → Зберегти**. Разом з фото й аудіо зберігається файл `*_notes.txt` з текстами та індексом файлів.

## Оновлення версії

Після змін треба підняти `VERSION` у `sw.js` (і `APP_VERSION` у `app.js`). Телефон покаже сповіщення «New version available → Update».
